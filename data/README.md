# data/ — Tier-0 simulated lens populations

Generated by `../scripts/generate_tier0.py`, built on `../src/lensing/` (see that
module's docstrings for exact citations to the papers each choice reproduces).
Every population here is disposable and regenerable from its `manifest.json` —
nothing in `data/` should be hand-edited.

## Populations (as of 2026-09-10)

| Folder | n | Config | Purpose |
|---|---|---|---|
| `tsang_fixed60/` | 2000 | Tsang+2024 operating point, c=60 | Primary positive population — "as published" baseline |
| `tsang_fixed15/` | 2000 | Same, c=15 | RQ4: concentration realism ablation (Tsang's own "random guessing" regime) |

| `multipole_m4_a1/` | 1000 | No subhalo, m=4 multipole at 1% of θ_E | RQ2 confounder, weaker amplitude |
| `multipole_m3_a3/` | 1000 | No subhalo, m=3 multipole at 3% of θ_E (generation seed 2: same macro-lenses and sources as `multipole_m4_a3/`) | Round-4 referee test: the lens-shape form the m=4 macro-model fix was not built for |

Each folder contains:
- `images_full_noiseless.npy`, `images_control_noiseless.npy` — float32 `(n, 64, 64)`. "Control" is the paired ablation (no-subhalo, or no-multipole if no subhalo is present) rendered with the *same* macro-model, source and noise draw — so `full - control` is exactly the perturbation's signature, nothing else.
- `images_full_noisy.npy` — the noisy version actually meant for training/detection (omitted where `--noiseless-only` was used, i.e. the confounder/control populations, since ablation studies need clean signal).
- `truth.jsonl` — one JSON object per line, index-aligned with the arrays: full macro-model, source, subhalo (mass, concentration, position — or `null`), multipole (order, amplitude, angle — or `null`), and which control variant was rendered.
- `manifest.json` — the complete `SimConfig`, instrument band settings, seed, package versions, platform, generation timestamp. This is what makes a population reproducible; if you need it again, don't regenerate by guessing flags — read the manifest and call the script with the same config name and seed.

## Regenerating

```
source ~/myenv/bin/activate
python ../scripts/generate_tier0.py --config <name> --n <N> --out data/<name> --seed <seed>
```

`--config` choices are listed in `generate_tier0.py`'s `CONFIGS` dict; add a new one in `../src/lensing/config.py` (as a documented preset, citing what it reproduces) before adding it there.

## Known limitations of this first cut (tracked, not hidden)

- Source is single-Sersic, not COSMOS (Tier 1 upgrade — `../problem_statement.md` §4.1). Matching Tsang+2024's exact reported numbers needs COSMOS cutouts via `galsim`.
- Fixed z_lens=0.5, z_source=1.0 for every image (matches most of the literature's own limitation, not fixed yet).
- Subhalo placement is a uniform annulus around θ_E, not Tsang's pixel-brightness-weighted criterion (documented approximation, see `SubhaloConfig.note`).
- External shear prior is our own choice (not stated in Tsang+2024's text) — see `LensConfig.note`.
- No lens light, no line-of-sight halos yet (Tier 2 items still to build: LOS population, unresolved sub-threshold population, lens-light residual).
